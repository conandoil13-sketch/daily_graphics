# Grarogue Daily Graphic Prototype

일상의 기록을 1000 x 1000 픽셀 그래픽으로 변환하는 모바일 앱형 웹 프로토타입입니다.

현재 버전은 GitHub Pages 같은 정적 호스팅에 올릴 수 있도록 HTML, CSS, JavaScript만 사용합니다. 서버나 빌드 과정은 필요하지 않습니다.

## Concept

하루의 기록은 다음 구조로 입력됩니다.

```txt
행위 카테고리
수치적 데이터
단위
감정상태 optional
```

입력된 기록은 오늘의 그래픽에 즉시 반영됩니다. `하루를 마침`을 누르면 그래픽 이름을 정하고, 해당 날짜의 출력물이 달력에 저장됩니다.

마감 후에는 원본 로그가 사라지고 완성된 그래픽 데이터만 남습니다.

## Activity Categories

현재 지원하는 행위 카테고리는 다음과 같습니다.

| 카테고리 | 단위 |
| --- | --- |
| 이동 | 걸음, 분, m, km, 횟수 |
| 식사 | 횟수, 칼로리, 포만감, 분, 점수 |
| 대화 | 분, 초, 횟수, 메시지, 사람 |
| 작업 | 분, 시간, 세션, 집중도, 작업수 |
| 휴식 | 분, 시간, 일, 회복감, 횟수 |
| 상태 | 점수, 강도, 활력, 피로도 |

## Graphic Rules

그래픽은 100 x 100 내부 그리드에서 생성되고, 최종 출력 시 1000 x 1000 PNG로 렌더링됩니다.

같은 날짜, 같은 카테고리, 같은 수치, 같은 단위, 같은 감정은 같은 결과를 재현합니다.

수치값은 숫자만 추출해 사용합니다.

```txt
"7,324 steps" -> 7324
"90분" -> 90
```

수치값에서 주로 사용하는 정보는 다음과 같습니다.

| 값 | 역할 |
| --- | --- |
| 끝 두 자리 | 위치 결정 |
| 자리수 길이 | 레이어 수, 크기, 두께, 복잡도 결정 |
| 전체 숫자값 | 보조 위치, 왜곡 강도 결정 |
| 각 자리 숫자의 합 | 색상 변화에 일부 사용 |
| 단위 | 아주 작은 위치/색상 보정 |

단위는 그래픽을 크게 바꾸지 않습니다. `-2px ~ +2px` 수준의 작은 위치 보정과 약한 색상 보정만 적용해, 같은 수치의 구조는 유지하면서 미세한 뉘앙스만 달라지게 합니다.

## Category Behavior

### 이동

수직선 또는 수평선이 생성됩니다. 끝 두 자리 숫자가 선의 기준 위치가 되고, 자리수가 길수록 선 레이어가 늘어납니다.

```txt
1-2자리: 1개 레이어
3-4자리: 2개 레이어
5-6자리: 3개 레이어
최대 5개 레이어
```

### 식사

원형 덩어리가 생성됩니다. 끝 두 자리와 전체 숫자값이 중심 위치를 결정합니다.

자리수가 길어질수록 반지름이 커지고, 3자리 이상이면 주변 면 형태가 추가됩니다.

### 대화

시작점과 도착점을 잇는 선이 생성됩니다. 이후 세로 또는 가로 방향으로 미러링되어 대화의 반향처럼 보입니다.

### 작업

격자나 메쉬 구조가 생성됩니다. 끝 두 자리는 격자 간격에 영향을 주고, 자리수가 길면 추가 샘플링 점이 들어갑니다.

마지막에는 전체 구조가 위, 아래, 왼쪽, 오른쪽 중 한 방향으로 정렬됩니다.

### 휴식

기존 그래픽을 원형 범위로 잘라내거나 남깁니다. 아무것도 없는 상태에서 휴식만 입력하면 원형 영역을 먼저 만듭니다.

### 상태

기존 그래픽을 흐르듯 왜곡합니다. 숫자값이 클수록 왜곡 강도가 커지고, 빈 공간에 일정 간격의 점이 추가됩니다.

## Mood Rules

감정상태는 하나의 고정색이 아니라 색상 범위를 가집니다. 수치값, 자리수, 날짜 시드에 따라 해당 범위 안에서 실제 색이 결정됩니다.

| 감정 | 색상 범위 |
| --- | --- |
| 차분함 | 청록-파랑 계열, 낮은 채도 |
| 피곤함 | 탁한 노랑/갈색 또는 흐린 청색 계열 |
| 기쁨 | 노랑-연두 계열, 높은 명도 |
| 불안 | 붉은 자주 또는 보라 계열 |
| 복잡함 | 주황, 청록, 자주 계열 혼합 |
| 무감각 | 거의 무채색 |
| 선택 안 함 | 기본 혼합 팔레트 |

감정은 형태에도 영향을 줍니다.

| 감정 | 형태 변화 |
| --- | --- |
| 차분함 | 세로 미러링 |
| 피곤함 | 아래 방향 정렬 |
| 기쁨 | 세로 + 가로 미러링 |
| 불안 | 강한 흐름 왜곡 |
| 복잡함 | 일정 간격의 추가 샘플 점 생성 |
| 무감각 | 활성 픽셀을 중간 회색으로 변환 |

## Color System

현재 키 컬러는 다음 두 가지입니다.

```txt
#b3ea6c
#5de23d
```

마감 액션과 일요일 표기는 다음 색을 사용합니다.

```txt
#f26464
```

토요일은 `#5de23d`, 일요일은 `#f26464`로 표시됩니다.

## Storage

브라우저 `localStorage`를 사용합니다.

```txt
daily-graphic-entries
daily-graphic-outputs
daily-graphic-meta
```

`entries`는 오늘의 임시 기록입니다.  
`outputs`는 마감된 그래픽 아카이브입니다.  
`meta`는 활성 날짜 같은 앱 상태를 저장합니다.

## Local Preview

정적 파일이므로 간단한 로컬 서버로 확인할 수 있습니다.

```bash
python3 -m http.server 8001
```

브라우저에서 다음 주소를 엽니다.

```txt
http://127.0.0.1:8001/
```

## GitHub Pages

이 폴더를 저장소 루트로 올린 뒤 GitHub Pages에서 배포 소스를 루트로 설정하면 됩니다.

```txt
Settings -> Pages -> Deploy from a branch -> main / root
```

앱은 `index.html`에서 시작합니다.

## Optional Logo

로딩 화면은 다음 파일이 있으면 로고로 사용합니다.

```txt
assets/logo.svg
```

파일이 없으면 큰 `G` 텍스트를 폴백으로 표시합니다.
